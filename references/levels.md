## Level 1 — 基础计算闭环 + 双输入

**目标**：打通 出题→答题→判分→计时→入库。两位数加减。

**生成器方向**（generators/basic.ts）
随机两个两位数，随机 + 或 −（减法保证非负），精确判分（误差 0）。时间标准查 time_standards 表（见本文件末「时间标准」）。

**数字键盘组件**（components/Numpad.vue）— 核心复刻对象

- 屏幕键盘：`[重开][清空][退格]` / `± 7 8 9` / `. 4 5 6` / `确定 1 2 3` / `0`
- 可拖拽：上下调高、左右调位、双击恢复（原版截图明确）

> ⚠️ 截图修正键盘布局（见 references/computation-area.md §5）：上方为旧版推测布局，截图实证为 **3 列 5 行**，且基础计算与资料分析**两套不同布局**：
>
> - 基础计算版：`±/清空/退格` + `1 2 3` / `4 5 6` / `7 8 9` + `./0/确定`（重开为独立按钮，有±）
> - 资料分析版：`重开/清空/退格` + `1 2 3` / `4 5 6` / `7 8 9` + `./0/确定`（无±，负号自动生成）
>   实现时以 computation-area.md 为准。

- **双输入**：屏幕键盘与物理键盘走同一 input handler，状态同步
- 物理键盘主要映射（具体可调）：

| 物理键          | 动作       |
| --------------- | ---------- |
| 0-9 / `.` / `-` | 输入       |
| Backspace       | 退格       |
| Enter           | 确定/提交  |
| Escape          | 重开当前题 |
| Delete          | 清空       |

- 玻璃质感按钮（hover/active 半透明+模糊）

**答题流程**
生成 N 题→逐题展示（顶栏进度+计时）→双输入任一作答→确定→判分→完成写库→跳历史/再练。

**验收**

- [ ] 10 道两位数加减题
- [ ] 屏幕键盘和物理键盘都能输入，互不冲突
- [ ] 键盘可拖拽
- [ ] 判分+计时准确
- [ ] 时间标准按题型×题量查表显示
- [ ] 历史记录可见 1 条

## Level 2 — 资料分析填空题

**生成器方向**（generators/dataAnalysis.ts）

| 题型         | 方向                         | 误差 |
| ------------ | ---------------------------- | ---- |
| 估算前期量   | 给现期A、增长率r，求 A/(1+r) | ±3%  |
| 估算增长量   | 给现期A、r，求 A·r/(1+r)     | ±3%  |
| 百化分       | 给 n，求 1/n 的百分数        | ±2%  |
| 百化分(反向) | 给百分数，求对应 1/n         | ±2%  |
| 分数计算     | 给 a、b，求 a/b              | ±2%  |
| 年均增长率   | 给基期、现期、n年            | ±3%  |
| 基期比重     | 给 A、B、rA、rB              | ±3%  |
| 年平均量     | 给图表数据，求平均值         | ±1%  |

> 比较类(增量/基期/分数比大小)在 L3。参数范围按难度（简单/一般/困难）调节，实现时参照原版截图与资料分析常见数值。
> ⚠️ 截图补充（见 references/computation-area.md §4）：分数计算实拆为分子＜分母/分子＞分母两版（预填行为不同）；新增年平均量(±1%，图表呈现)、分数比大小(L3比较题)。误差值均为截图实证。

**百化分反向**：原版"反向练习"胶囊按钮——给百分数求 1/n。

**判分**：`|user-true|/true <= tolerance`

**呈现**：KaTeX 渲染分数/公式（"直接显示公式"模式）；"生成文字图表"模式 L4 接入。

**验收**

- [ ] 9 类题型各能出题（含百化分正/反向）
- [ ] 误差判断按表正确
- [ ] KaTeX 公式正确渲染
- [ ] 双输入可用于小数/负数答案

## Level 3 — 比较题 + 复合题

**比较题组件**（components/CompareQuestion.vue）

- 三类比较题：增量比大小、基期比大小、分数比大小（截图实证 #8#9#14）
- 两算式左右并排，中间绿色 `?`
- 底部：大于(绿) / 小于(橙) / 重开(薄荷绿) / 确定(灰)
- 物理键盘：`>` 或 `1`=大于，`<` 或 `2`=小于，Enter=确定（可调）
- 选中→确定→判分
- 详见 references/computation-area.md §10

**一表通算**（原版最复杂页）
给出现期A/B、增长率r1/r2、基期A'/B'、增长量x1/x2（多色标签）；
求现期比重P、基期比重P'、两期比重差d、比值增长率k；多结果逐个填空，允许误差 ±5%（截图明确）。

> ⚠️ 截图修正（见 references/computation-area.md §11）：实际为 **9 个结果**（非 4 个），新增：基期和S、基期差D、隔年增长率r、AB和增长率r3、AB差增长率r4。已知数据需先点"刷新数据"生成；底部有"随机/自定义"导航。

**验收**

- [ ] 比较题大于/小于交互（屏幕+键盘）
- [ ] 一表通算多结果填空
- [ ] 复合公式 KaTeX 渲染

## Level 4 — 设置项 + 自定义运算

**设置页**（views/Settings.vue）

- 题型选择弹窗：随机/基期量/基期差/增长量/增长率/间隔增长率/平均数增长率/混合增长率
- 难度：简单/一般/困难 → 影响数值范围
- 题量：10/15/自定义5-100（滑块）

> ⚠️ 截图修正题量选项（见 references/original-app.md「设置页」）：资料分析页实为 5/10/15/20/25/自定义 六按钮；基础计算页用弹窗三模式（快速10/正常15/自定义5-100滑块）。上方为旧版推测，实现以截图为准。

- 呈现方式：生成文字图表 / 直接显示公式
- N-back：关/1-back/2-back
- 开始答题 / 练习历史 / 导出题目

**自定义运算**（generators/custom.ts）

- 标准：第一位数(1-4位)、运算符(多选+−×÷)、第二位数(随机位数/固定/范围)
- 幂运算：底数(按范围/按位数)、类型(平方/立方)
- "最近使用"持久化

**N-back**：答题时额外问"n 步前那题答案"，答错扣分（认知负荷训练）。

**验收**

- [ ] 设置全可配置并持久化
- [ ] 配置生效到出题
- [ ] 自定义运算(标准+幂)能生成
- [ ] N-back 1/2 可启用

## 时间标准（可配置）

不同题型 × 不同题量 → 不同合格/良好/优秀秒数。存 SQLite time_standards 表（见 data-model.md），设置页可编辑。

生成器出题按 `题型 + 题量` 查表取标准；查不到用题型默认；全无用全局默认。

| basic_addsub  | 10   | 28   | 22   | 18   |
| basic_addsub  | 30   | 90   | 70   | 55   |
| frac_calc     | 10   | 40   | 30   | 22   |
| estimate_prev | 10   | 35   | 26   | 20   |
| baihua_frac   | 10   | 30   | 22   | 16   |
