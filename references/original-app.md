## 历史记录页 ✅(#26)

- 顶栏标题 `历史记录`。
- 筛选行：`全部`(下拉，按题型筛选) + `清除记录`(深绿按钮)。
- 横幅：`总正确率：95.44%`（绿底白字）。
- 分页：`每页 10 条` + `显示 1-10 / 114`（实证 114 条记录）。
- 卡片格式（每条两行）：
  - 行1：`序号. 日期 时间 题型`（如 `1. 2026-7-2 11:40:58 三位数乘一位数`）
  - 行2：`答对情况：X/Y 用时：H:M:S秒 评语`（如 `答对情况：26/30 用时：0:2:52秒 加油`）
  - 右侧 `▼` 展开箭头（🟡 推断展开后显示逐题详情）。
- ✅ 评语统一为 `加油`（鼓励语），**非** 合格/良好/优秀。
- ✅ 自定义运算题型在历史中显示为标签式（如 `4位数-4位数`）。

> why 评语用"加油"而非档位：合格/良好/优秀是**计时目标**（答题屏显示），会话评语用鼓励语降低挫败感、维持练习动力。

## 自定义运算 ✅(#24#25)

> 弹窗两个 tab：标准运算 / 幂运算。

### 标准运算 tab ✅(#24)

- **第一个数**：1位数 / 2位数(选中) / 3位数 / 4位数
- **运算符号（可多选）**：+(选中) / - / × / ÷
- **第二个数**（三模式切换）：
  - 随机位数(选中) → 子选项 1/2/3/4 位数
  - 固定数字 → 🟡 推断输入固定值
  - 随机范围 → 🟡 推断输入最小~最大值
- **最近使用**标签：`4位数-4位数` / `2位数-2位数` / `4位数×1位数` / `2位数-15~99` / `2位数-10~99`
- 底部 `取消` / `确定`(绿) + 蓝色 + FAB

### 幂运算 tab ✅(#25)

- **底数设置方式**：按范围(选中) / 按位数
- **数字范围限制**（按范围时）：`最小值` ~ `最大值` 两输入框
- **运算类型（可多选）**：平方(选中) / 立方
- 底部 `取消` / `确定`(绿) + 蓝色 + FAB

> 与 levels.md L4 自定义运算方向一致，补充实证：第二个数三模式、幂运算最小/最大值输入、最近使用标签格式。
